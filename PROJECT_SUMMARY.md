## 🎯 How to Use

### Right Now (Local Network)
The server is running! Access at the network address shown on screen.

### Build Desktop App
**Windows:**
```bash
# Double-click this file:
build-app.bat
```

**Mac/Linux:**
```bash
./build-app.sh
```

The installer will be in the `dist` folder.

### Deploy to Railway
See `RAILWAY_DEPLOY.md` for complete guide:
1. Create Railway account
2. Connect GitHub repo
3. Deploy (automatic)
4. Add S3 for persistent storage (optional)
